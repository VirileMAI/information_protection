# Проверка вероятностного простого числа с BigInt

Эта утилита использует библиотеку `big_int.c/.h` для запуска 100 раундов трёх вероятностных проверок простоты над двумя
произвольной длины целыми числами: Миллера–Рабина, сильного теста Лукаса и комплексного теста Баийи–Померенца–Селфриджа–Уогстаффа
(Baillie–PSW). Программа продолжает линию предыдущих лабораторных работ: все операции над числами выполняются через тип `BigInt`,
поэтому код легко расширять и повторно использовать вместе с остальными заданиями.

## Как собрать

```bash
gcc -std=c11 -O2 probabilistic.c big_int.c -o probabilistic
```

Файл `big_int.c` подключается напрямую, поэтому дополнительных библиотек не требуется.

## Как запустить

```bash
./probabilistic [<простое> <составное>]
```

- Если аргументы не указаны, используются числа из файлов лабораторной работы: предполагаемое простое `32416190071` и
  составное `32416190069`.
- Каждый запуск выполняет по 100 раундов трёх тестов: Миллера–Рабина (базы 2, 3, 5, 7, 11), сильного Лукаса с параметром Selfridge и
  комбинированного Baillie–PSW (тест Миллера–Рабина по базе 2 + сильный тест Лукаса).
- Все арифметические действия (деление, умножение, возведение в степень) выполняются средствами `BigInt`.

В отчёте выводятся количество успешных и неуспешных раундов для каждого теста, а финальный вердикт основан на Baillie–PSW.

## Интерпретация результатов

- `passes=100 fails=0` — число прошло все раунды конкретного теста и считается вероятно простым с точки зрения этого критерия.
- `passes<100` — на части раундов число отклонено. Если отклонены все 100 раундов, перед вами гарантированно составное число.
- Важнее всего столбец Baillie–PSW: его 100 отказов означают, что число точно составное, а 100 успешных проверок дают очень
  высокую степень уверенности в простоте.

## Связь с библиотекой `big_int`

- Константы, копирование, деление на 2, вычисление остатка и возведение в степень реализованы через вспомогательные функции,
  которые опираются на `bi_add`, `bi_sub`, `bi_mul`, `bi_div` и т. д.
- Код не использует 64-битные типы для хранения кандидатов, благодаря чему можно проверять числа произвольного размера.
- При необходимости можно заменить набор баз, добавить дополнительные тесты или интегрировать программу в основное меню
  лабораторной работы без изменения формата входных данных.
